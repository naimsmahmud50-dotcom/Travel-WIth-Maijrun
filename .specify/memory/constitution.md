# Travel With Maijrun — Engineering & Architectural Constitution

## Core Principles
1. **Zero Collateral Modification**: Only modify code strictly scoped to the targeted feature or section. Never touch unrelated files, APIs, auth, or components.
2. **Deterministic Verification**: Every modification must pass 100% of existing tests in `test/` and compile cleanly with `npm run build`.
3. **Ultra-Luxury Aesthetics**: Follow the design language of high-end luxury hospitality (Aman, Abercrombie & Kent, Belmond) with Cormorant Garamond serif headings, `#D4AF37` gold accents, `#0B2019` emerald green, and smooth uninterrupted motion.
4. **Accessible & Responsive**: High-contrast typography, screen-reader labels, responsive breakpoints across mobile, tablet, and desktop.
