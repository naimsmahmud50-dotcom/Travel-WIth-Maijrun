> **A World-Class Ultra-Luxury Travel Experience Reimagined for the Modern Conscious Traveler.**

Reverse-engineered from the architectural and aesthetic hallmarks of global leaders like **Abercrombie & Kent (A&K)**, redesigned with a **100% Halal Luxury Hospitality Standard** (Islamic-friendly privacy, Michelin-starred halal gastronomy, spiritual pacing, and private retreats).

## 🌟 Key Features & Architectural Highlights

### 1. Cinematic Hero Slideshow with Ken Burns Transitions
- Seamless automated transitions between royal travel destinations.
- Continuous slow pan/zoom animation on luxury high-definition imagery.
- Integrated quick-action CTAs and slide indicators.

### 2. Bespoke Journey Finder (Floating Dock)
- Filter by destination (Makkah & Madinah, Moorish Andalusia, Maldives, Swiss Alps, Bosphorus, Serengeti).
- Filter by travel style (Spiritual, Heritage, Secluded Honeymoon, Family Multi-Gen, Safari).
- Season / Departure selector.

### 3. The Maijrun Standard of Excellence (Halal Luxury Pillars)
- **100% Halal Gourmet:** Michelin-trained private chefs, hand-slaughtered certified halal meats, alcohol-free banquets.
- **Absolute Family Privacy:** Zero-sightline private pool villas, private yacht charters, private island pavilions.
- **Prayer-Friendly Pacing:** Choreographed around daily Salah times, Qibla indicators, and stops at historical mosques.
- **24/7 Dedicated Concierge:** Personal travel butlers, VIP tarmac limousine airport escorts.

### 4. Interactive Destination Portfolio & Real-time Currency Converter
- Live currency switcher: **BDT (৳)**, **USD ($)**, **AED (د.إ)**, **GBP (£)**, **EUR (€)**.
- Destination filtering tabs: All, Pilgrimage, Heritage, Islands & Seclusion, Alpine & Nature.

### 5. Interactive Bespoke Inquiry & Concierge Modal
- One-click booking consultation tailored to specific destinations.
- Direct WhatsApp VIP Concierge floating trigger.

## 🚀 How to Run & Preview

### Option A: Instant Browser Preview (Zero Installation Needed)
Simply open `index.html` in your web browser:
```bash
google-chrome "/home/mahmud-hasan/Naims Project/Travel With Maijrun/index.html"
```
Or double-click `index.html` from your file manager. It works 100% out of the box with all styling, animations, icons, and interactive modals!

### Option B: Modern Next.js 14/15 Development Server
```bash
cd "/home/mahmud-hasan/Naims Project/Travel With Maijrun"
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the Next.js React version.
